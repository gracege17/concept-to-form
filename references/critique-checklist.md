# Design Critique Checklist

## A. Brief fidelity
- [ ] Objective, audience, tone and requirements remain correct.
- [ ] Client-confirmed preferences are distinguished from our interpretations.
- [ ] Required words, spelling, date and place are checked against source.

## B. Concept and visual principle
- [ ] One dominant idea can be stated in one sentence.
- [ ] The key visual relationship makes that idea visible.
- [ ] No irrelevant symbolism has been added to justify empty space.
- [ ] The audience is represented with agency and dignity.

## C. Formal design
- [ ] Strong focal point and typographic hierarchy.
- [ ] Usable negative space, contrast and legibility.
- [ ] Proportion, geometry, lighting and perspective are internally consistent when applicable.
- [ ] Material and print effects feel deliberate rather than synthetic.
- [ ] Works at actual physical size.

## D. Element audit

For every major element complete:

| Element | Communication function | Formal function | Keep / remove / change | Why |
|---|---|---|---|---|

If removing an element does not weaken meaning, hierarchy, clarity, rhythm or balance, consider removing it.

## E. Controlled iteration

- [ ] State what is broken and why.
- [ ] Propose one high-impact change.
- [ ] Lock all decisions the user wants preserved.
- [ ] Compare before/after against the same criterion.
- [ ] Log the decision rather than generating endless untracked variations.

## Problem levels

**Wrong message?** Return to UNDERSTAND / CONCEPT.
**Weak metaphor?** Return to VISUAL PRINCIPLE.
**Does not scale?** Return to GRAPHIC SYSTEM.
**Looks cluttered?** Start with hierarchy and element audit.
**One detail is wrong?** Edit only that detail.
